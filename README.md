## Mock WebSocket Server

Для тестирования с демонстрационными данными:

```bash
npm run mock-server -- --delay 50   # Start mock server (50ms delay)
npm run dev                         # Start app in another terminal
```

Откройте `http://localhost:5173/live?dev=1` для просмотра.

## Схема трека и прогноз пита

Для просмотра новой схемы на записи с исходным темпом сообщений:

```bash
npm run mock-server:track
npm run dev
```

Открыть `http://localhost:5173/live/?dev=replay`. Перезагрузка начинает
повтор сначала, незадолго до первого питстопа. Это запись `gg5a.txt`
с демонстрационными метаданными Premium / стандарт для проверки UX,
а не запись Premium. `REPLAY_START` задаёт начало в миллисекундах заезда.

В live схема использует `serverTime` кадра и `laps[].receivedAt` (Unix ms),
`track` и `direction` из обновлённого timing-ws. Без времени положение
остаётся неизвестным. `receivedAt` — время получения круга коллектором;
задержка источника влияет на точность схемы и порог обнаружения пита.
Прогноз разрешён только для `premium`, `direction: 1`; остальные треки
и обратное направление показывают базовую схему.

Тап по строке таблицы или точке выбирает пилота и сразу открывает покруговку. На узком экране
в таблице остаётся только ожидание, оба значения доступны под схемой.
